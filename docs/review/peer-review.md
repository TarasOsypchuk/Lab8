# Крос-рев'ю (Peer Review)

- **Завдання ЛР:** 6
- **Учасники:** Студент А — Решко, Студент Б — Осипчук.
- **Формат:** кожен відкриває Pull Request зі своєї гілки в `main`, другий рецензує його на GitHub (коментарі до рядків + Approve / Request changes). Цей файл — підсумок рев'ю для звіту.

## 1. Порядок проведення

1. Студент А відкриває PR `feature/Reshko → main` (завдання 1–3). Студент Б рецензує за чек-листом (п. 2).
2. Студент Б відкриває PR `feature/<Осипчук> → main` (завдання 4–5). Студент А рецензує.
3. Кожне зауваження — окремий коментар до рядка з категорією `[blocker] / [major] / [minor] / [question]`.
4. Автор виправляє або аргументовано відповідає. Після Approve — merge.
5. Підсумок (таблиця п. 4) переноситься в цей файл.

## 2. Чек-лист рецензента

**Information Expert / Creator**

- [ ] Обчислення виконує клас, що володіє даними (немає `getX().getY()` з подальшою арифметикою поза сутністю).
- [ ] Немає public-сеттерів. Поля `private final`, крім обґрунтованого стану (`status`).
- [ ] Колекції віддаються як незмінні (`List.copyOf`).
- [ ] Невалідний об'єкт неможливо створити (фабричний метод перевіряє інваріанти).

**Controller / Indirection / Pure Fabrication**

- [ ] `ConsoleUi` не містить обчислень і бізнес-правил.
- [ ] `RegisterSubscriptionUseCase` не містить `Scanner`, `System.out` і формул.
- [ ] Контролер і домен залежать від інтерфейсів-портів, а не від `InMemory*`.
- [ ] Конкретні класи створюються лише в `FitnessClubApp`.

**Polymorphism / Protected Variations**

- [ ] Немає `if/switch` за кодом тарифу в домені й контролері.
- [ ] Новий тариф або знижку можна додати новим класом без зміни існуючих.
- [ ] Числові константи цін зібрані в `DefaultTariffs`.

**Low Coupling / High Cohesion**

- [ ] `metrics-generated.md` перегенеровано після останніх змін.
- [ ] CBO_core ≤ 4 і LCOM4 = 1 для ключових класів. Винятки задокументовані.
- [ ] Закон Деметри: немає «поїздів» викликів (крім Fluent API і records).

**Загальне**

- [ ] `mvn test` зелений, характеризаційні тести проходять.
- [ ] Назви класів і методів відображають предметну область.
- [ ] ADR оновлено, якщо змінилося рішення.
